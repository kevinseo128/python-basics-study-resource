Getting Started

Learn the basic building blocks of Python.

1. Print

Print is used to display text or values on the screen.

Code Example

print("hello world")

Output

hello world

2. Variables

A variable stores a value that can be used later.

Code Example

num = 5
print(num)

Output

5

3. Input

Input lets the user enter information into the program.

Code Example

name = input("what is your name? ")
print("hello", name)

Output

what is your name? Karen
hello Karen
Tip: Use int() around an input when you want the user to enter a number.
