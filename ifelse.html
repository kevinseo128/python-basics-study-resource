If / Else

Learn how Python can make decisions using conditions.

1. If

An if statement runs code when a condition is true.

Code Example

x = 2
if x < 20:
  print("apple")

Output

apple

2. Elif

Elif can be used to check another condition.

Code Example

fruit = input("what fruit do you like? ")

if fruit == "apple":
  print("yum")
elif fruit == "pear":
  print("juicy!")
else:
  print("yuck")

Output

what fruit do you like? pear
juicy!

3. Else

Else runs when the if condition is not true.

Code Example

x = 30
if x < 20:
  print("apple")
else:
  print("orange")

Output

orange
Tip: Use == when checking if two values are equal.
