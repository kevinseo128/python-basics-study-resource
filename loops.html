Loops

Learn how loops can repeat code in Python.

1. For Loop

A for loop repeats code a set number of times.

Code Example

for number in range(5):
  print(number)

Output

0
1
2
3
4

2. While Loop

A while loop repeats code while a condition is true.

Code Example

number = 1

while number <= 3:
  print(number)
  number = number + 1

Output

1
2
3
Tip: Make sure the condition can become false so the loop can stop.
